# Yash Saini — Portfolio and Web Basics Quiz

A static personal portfolio and a five-question HTML/CSS/JavaScript quiz built with AI assistance.

## Run
Open index.html in a browser or run `python3 -m http.server 8000` from this directory and open http://localhost:8000.

## Files
- index.html: profile, projects, and quiz markup
- style.css: responsive layout and theme colors
- app.js: saved theme, quiz scoring, feedback, and restart

## Check
Switch themes and reload. Answer five questions, check the score, then restart. With keyboard navigation, Tab reaches each control and Enter activates it.

## Deploy
In a GitHub repository, open Settings → Pages, select deployment from a branch, and publish the root of main. The site has no build step or secrets.
